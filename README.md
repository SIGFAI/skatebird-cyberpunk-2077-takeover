# Cyberpunk 2077 Takeover

**skatebird** × Cyberpunk 2077 · visual · idea by the team

Bring Cyberpunk 2077 into the game in the most visible and funny way. The change shows in the first 30 seconds of play.

> I dropped Night City into SkateBIRD: neon towers, rain, a snarky rock-star bird on the radio and a police drone that fines you for screaming.

## Install

Install BepInEx 5 (64-bit) into your SkateBIRD folder, then copy the SigfMix folder from this mod's BepInEx/plugins into BepInEx/plugins. Start the game and you land in the neon city playground.
